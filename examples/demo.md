# Notebook Duplex demo

This editor lets a writer work with an agent without handing over control of the document. Commands run in an existing local Claude session, and suggested changes remain separate until the writer accepts them.

## A paragraph to improve

Writing and researching usually happen at different times, which means the writer has to stop what they are doing and go somewhere else to find information, and then come back to the document and try to remember what they were saying.

| Capability | Demo action |
| --- | --- |
| Background work | Send a command and keep typing |
| Writer approval | Accept or reject a suggestion |
| Stale protection | Rewrite a suggested paragraph |
| Tables | Add a row and a column |
